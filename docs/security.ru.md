# Данные и безопасность обновлений

[Главная](../README.ru.md) · [English](security.en.md)

## Источники данных

| Источник | Для чего используется |
| --- | --- |
| Локальное соединение AION 2 через Npcap | Бой, цель, коллекция, навыки и объекты рядом |
| Локальные игровые каталоги и изображения | Метки карты, названия, иконки классов, навыков и ресурсов, справочные места |
| Публичные профили NCSOFT | Дополнительная экипировка, БМ, ГС и арканы по имени, серверу и региону |
| GitHub Releases этого репозитория | Описание обновления и установочные пакеты |
| npcap.com во время установки | Официальный Npcap при отсутствии драйвера |

Запросы профилей направляются к `api-search.plaync.com` и `aion2.plaync.com`. Автоматическую загрузку можно отключить в настройках. Ручной запрос профиля выполняется по вашей команде.

Программа не запрашивает игровой пароль, cookies входа или токен GitHub. История боёв и сырые пакеты автоматически не отправляются. Сервисы профилей и обновлений получают сетевые запросы, необходимые для своих функций.

## Локальное хранение

Данные находятся в `%LOCALAPPDATA%\NauchpopTools.Next`: настройки, расположение окон, коллекция, последние бои и скачанные обновления. Экспорт отчёта и резервное копирование — действия пользователя. Удаление программы сохраняет данные и не удаляет общий драйвер Npcap.

## Проверка обновления

1. Приложение получает `update.json` из закреплённого репозитория GitHub.
2. Проверяет исходные байты описания закреплённым RSA-ключом: RSA-PSS и SHA-256.
3. Проверяет репозиторий, платформу, версию, имя установщика, размер и дату выпуска. Та же или более старая версия к установке не допускается.
4. Загружает файл по HTTPS с проверкой переходов GitHub/CDN и ограничением размера ответа.
5. Сверяет размер и SHA-256 установщика. Прерванный или неправильный файл не становится готовым к установке.
6. Перед запуском программа и помощник повторно проверяют кэш. Помощник ждёт сохранения данных и завершения приложения, затем открывает Setup со штатным запросом прав Windows.

Закрытый ключ подписи не входит в клиент и публичный репозиторий. Авторизация GitHub на компьютере игрока не требуется.

Подпись описания и Windows Authenticode — разные механизмы. У текущего Setup EXE нет сертификата издателя Authenticode. Подпись манифеста не подтверждает произвольные файлы с посторонних сайтов.

## Сообщения о проблемах безопасности

Укажите версию и поведение, не публикуя учётные данные, частные сведения профиля и исполняемые атакующие файлы в обычном отчёте. Публичный репозиторий содержит документацию и выпуски; исходники приложения остаются закрытыми.
