# Установка и руководство игрока

[Главная](../README.ru.md) · [English](guide.en.md)

## Требования

- Windows 10 или Windows 11, 64-битная версия.
- AION 2 на том же компьютере.
- Npcap для локального захвата пакетов. При отсутствии драйвера Setup загрузит официальный мастер.
- Интернет для скачивания выпусков и дополнительных публичных профилей. Карты, изображения и сохранённый прогресс находятся локально.

В Windows x64 сборку включена .NET. Устанавливать SDK и собирать программу не нужно.

## Установка

Скачайте последний **Setup EXE** из [Releases](https://github.com/squortexxx/AION-2-Tools/releases/latest). Запустите его, выберите язык и папку, завершите мастер. Если Npcap отсутствует, пройдите его отдельную официальную установку. Оставьте стандартные параметры Npcap, если ваша среда не требует других.

Если Npcap запросил перезагрузку, перезагрузите Windows и завершите установку до проверки подключения. Повторно устанавливать уже обнаруженный драйвер при обновлении Nauchpop не требуется.

Для переносимой ZIP-версии распакуйте все файлы в доступную для записи папку. Запустите из неё `NauchpopTools.Next.exe`; одного EXE недостаточно.

## Первое подключение

Запустите Nauchpop tools и войдите в игру. В **Настройки → Подключение** задайте имя персонажа, регион и сервер. Для публичного профиля должны совпадать имя, регион и сервер. В формах персонажа и аркан тоже есть выбор региона и сервера: одно название в разных регионах имеет разные ID.

Чтобы получить данные, откройте соответствующие игровые окна:

| Действие в игре | Какие данные помогает получить |
| --- | --- |
| Нанести урон в группе | Игроки, групповой ДПС, класс и урон навыков |
| Выбрать противника | Здоровье и сохраняемую сводку цели |
| Открыть коллекцию питомцев / душ | Уровни коллекции и оставшиеся души |
| Открыть навыки / поменять панель | Изученные навыки, уровни и слоты панели |
| Открыть список мировых боссов | Состояние и время появления |
| Открыть рейтинг / поиск группы | Позицию в рейтинге и объявления |

Если приложение запущено после получения клиентом начального состояния, может понадобиться игровая активность или повторный вход персонажем.

## Язык

Первый запуск — на **английском**. В **Settings → Interface language** выберите **Русский**. Главное окно, оверлеи и выбор голоса переключатся сразу. Текущий бой, коллекция и расположение окон сохранятся.

Имена персонажей, ваши подсказки и личные задачи сохраняют исходный текст. Для речи используется установленный голос Windows выбранного языка; если его нет, звучит сигнал.

## Управление оверлеями

| Управление | Действие |
| --- | --- |
| Переключатели в пространстве | Показать или скрыть отдельные панели |
| Расставить окна / Ctrl + Alt + M | Войти в режим расположения или выйти из него |
| Готово / Escape | Закончить настройку |
| Удерживать Alt | Взаимодействовать с оверлеями во время игры |
| Потянуть заголовок | Передвинуть окно при включённом взаимодействии и незакреплённой позиции |
| Потянуть правый нижний угол | Независимо изменить ширину и высоту |
| Меню панели / Ctrl + колесо мыши | Отдельно изменить размер текста |
| Кнопка закрытия панели | Скрыть панель; вернуть её можно в пространстве |

В обычном режиме клики проходят сквозь оверлеи в игру. Панели видны при активной игре или настройке расположения. Рекомендуется оконный режим или окно без рамки: эксклюзивный полный экран может скрывать оверлеи рабочего стола.

## Бой

В панели боя доступны **Я / Группа** и **Все цели / Только боссы**. Карточки сохраняют порядок при обновлении значений. Нажмите игрока для детализации навыков. Новый бой можно начать вручную; предыдущий также завершается после настроенной паузы без урона. Лечение учитывается отдельно и не продлевает интервал урона.

Цель находится в отдельном окне и остаётся после смерти. БМ/ГС появляются только из игровых данных или совпадающего публичного профиля; недостающие значения не подменяются.

## Экипировка

В **Персонаже** показаны надетые вещи из публичного профиля. Данные известного персонажа загружаются при открытии, если включены автоматические публичные профили. **Загрузить** запрашивает свежие сведения; фоновая загрузка сохраняет обычный кэш.

Используйте поиск и фильтр категории. Нажмите карточку для уровня, характеристик, бонусов усиления, магических камней, навыков и доступных источников. Список и подробности прокручиваются независимо. Одинаковые ID в разных слотах, например у колец, сохраняют отдельные данные. Здесь отображается надетая экипировка; содержимое всего рюкзака этот экран не обещает.

Игровые иконки включены в пакет, где доступны. Недостающие PNG загружаются только с официального CDN и сохраняются локально. Отсутствие изображения не мешает просмотру вещи.

## Охота, атлас и кубы

В **Охоте** найдите питомца, выберите фильтр прогресса и закрепите нужные цели. В оверлее доступны **Добавить**, **Из цели** и снятие отслеживания. Кнопки карты показывают известные места и оставшиеся души. Оценка необходимых убийств появляется только после достаточного числа замеченных выпадений.

В **Атласе** выберите карту, слой, тип ресурса или поиск по названию. У ресурсов есть игровые иконки; наведите мышь для названия и нажмите для подробностей. Постройте маршрут до 12 справочных мест и переходите к следующей точке вручную. Программа не двигает персонажа.

Алерты о кубах включены по умолчанию; радиус при свежей позиции — 120 м. Радиус, сигнал и звук меняются в **Настройках**. При неизвестной или устаревшей позиции уведомление может сообщить о кубе в загруженной области без выдуманного расстояния. Повторы одного объекта подавляются.

## Подсказки босса и события

В **Механиках** укажите ID навыка и подсказку либо возьмите текущий замеченный навык. Во время соответствующего каста окно покажет инструкцию и сможет озвучить её. Подсказку можно редактировать прямо в оверлее. Это ваши заметки по навыкам, а не полная встроенная библиотека тактик.

В **Событиях** выберите напоминания. Время показано в вашем часовом поясе; сигнал звучит за минуту до начала. Справочное расписание и замеченное время мирового босса — разные источники: расписание не гарантирует живое появление.

## Обновления

Раздел **Обновления** в боковой панели позволяет проверить новую версию вручную. Автопроверка выполняется после запуска и раз в 12 часов, её можно отключить. Если выпуск доступен:

1. Прочитайте описание и нажмите **Скачать обновление**.
2. Дождитесь проверки подписи, размера и контрольной суммы. Загрузку можно отменить.
3. Закончите бой и нажмите **Установить и перезапустить**.
4. Программа сохранит данные и закроется. Подтвердите штатный запрос прав Windows и завершите Setup.

Уже скачанный корректный пакет может использоваться после перезапуска приложения. Повреждённые, изменённые и неполные пакеты блокируются. Пользователям 0.6.1 нужно один раз вручную установить 0.7.0 для получения встроенного обновления.

## Данные и удаление

Настройки, окна, коллекция и бои находятся в `%LOCALAPPDATA%\NauchpopTools.Next`. Перед ручным резервным копированием закройте программу. Обновление и удаление сохраняют эти файлы. Npcap — общий драйвер; деинсталлятор Nauchpop его не удаляет.

## Решение проблем

| Симптом | Что проверить |
| --- | --- |
| Ожидание AION 2 | Войдите в игру, проверьте наличие Npcap и выполните игровые действия. При необходимости перезайдите персонажем. |
| Нет БМ или ГС | Проверьте имя, сервер, регион и автозагрузку профилей. Закрытый или недоступный профиль не отдаёт характеристики. |
| Нет коллекции / навыков | Откройте соответствующее окно в игре для получения состояния. |
| Нет пинга | Дождитесь поддерживаемого ответа игры. Старые измерения намеренно скрываются. |
| Оверлей не двигается и не нажимается | Удерживайте Alt или включите настройку расположения. Проверьте закрепление позиции. |
| Горячая клавиша занята | Используйте кнопку «Расставить окна». Клавишу может занимать другая программа или копия Nauchpop. |
| Панели не видны | Включите их в пространстве, активируйте игру и используйте окно без рамки. Режим расположения поможет найти окна. |
| У метки карты нет живого объекта | Атлас содержит справочные точки. Живое сообщение — отдельный сигнал. |
| Обновление не проходит проверку | Отмените и повторите загрузку из Releases этого репозитория. Изменённый файл из кэша запускать не следует. |
| Захват сломался после патча игры | Укажите версию игры и затронутую функцию. Поддержка протокола может потребовать обновления программы. |

Setup EXE пока не подписан сертификатом Authenticode. Подпись описания обновления подтверждает содержимое выпуска; это отдельный механизм, не заменяющий подпись издателя Windows.

В [сообщении об ошибке](https://github.com/squortexxx/AION-2-Tools/issues/new?template=bug_report.md) укажите версию приложения, Windows, регион игры, шаги и видимое состояние. Пароли, токены и сырые захваты пакетов прикладывать не нужно.
