# Third-party components

Nauchpop tools uses the WPF UI component library, SharpPcap and PacketDotNet, and protocol/catalog work from community AION projects including [A2Tools DPS Meter](https://github.com/taengu/A2Tools-DPS-Meter). Portions of game data and assets retain their upstream notices and ownership.

The release package includes a `licenses` directory with the applicable component licenses, copyright notices and asset-source notes. These notices are retained when installing or updating the app.

Npcap is a separate dependency. It is downloaded from its official website when needed and is **not bundled** in Nauchpop releases. Its own license and installer apply.

Game images and names belong to their respective owners. This is an independent companion project, not an official NCSOFT product. This distribution repository does not publish the application source or grant ownership of third-party assets.
